Yuyang Wu

从零训一个小 GPT， 优化它的推理， 再接上 Agent harness。

一个项目做六步。每一步只用前面做出来的东西，结束时都有一个能判对错的检查：通过了才往下走。最后得到的 harness 能跑任务，也能说清任务失败在哪。

  1. 1

    Transformer

    学
    tokenization、embedding、causal attention、残差和归一化。
    做
    写一个小 GPT 的 forward。
    验
    改未来 token，前面位置的 logits 不变。
    练
    • Byte Pair Encoding (BPE) Tokenizer中
    • Add Positional Embeddings to Token Embeddings易
    • Implement Batched Causal Self-Attention中
    • Implement Layer Normalization for Sequence Data中
    • Pre-Norm GPT Transformer Block Forward Pass难
    • Build a Tiny GPT难

    「改未来 token」这个检查题库里没有，要自己写一个 assert。

  2. 2

    预训练

    学
    next-token loss、反向传播、AdamW、学习率、数据切分、checkpoint。
    做
    先让模型过拟合一个 batch。
    验
    用留出集区分「能训练」和「能泛化」。
    练
    • Construct Next-Token Prediction Targets易
    • Implementing Basic Autograd Operations中
    • Implement AdamW Optimizer Step中
    • Warmup + Cosine Decay Schedule中
    • Random Train/Validation/Test Split with Shuffling易
    • Preflight Checks Before a Long Training Run: Output Shape, Loss at Init, Overfit One Batch中
    • Detect Overfitting or Underfitting易
  3. 3

    后训练

    学
    SFT、LoRA、偏好数据，再比较 DPO 和 RL 的目标。
    做
    实际跑一次 LoRA SFT。
    验
    对同一组留出 prompts 比较训练前后，不只看训练 loss。
    练
    • Masked Cross-Entropy Loss for Supervised Finetuning中
    • LoRA: Low-Rank Adaptation Forward Pass中
    • Recursively Replace Linear Layers with LoRA中
    • Preference Dataset Collate Function for DPO难
    • Direct Preference Optimization (DPO) Loss中
    • Fine-Tune Model Weights with RLHF Policy Gradient中
    • Is the Difference Real? Comparing Two Checkpoints on a Benchmark Across Seeds中

    题库只覆盖 loss 和模块，完整跑一次 LoRA SFT 要自己做。

  4. 4

    推理与 Infra

    学
    采样、KV cache、prefill/decode、batching；理解量化和并行在省什么。
    做
    实现 KV cache。
    验
    先验证 logits 与无 cache 的版本一致，再量延迟和显存。
    练
    • Combined Token Sampling Pipeline (Temperature + Top-k + Top-p)难
    • A KV Cache for Autoregressive Decoding难
    • Classify LLM Prefill vs Decode as Compute-Bound or Memory-Bound中
    • Continuous Batching (In-Flight Batching) Simulator中
    • Compute TTFT ITL and TPS from a Token Timestamp Stream易
    • Estimate KV Cache Size from Model Config中
    • Implement INT8 Quantization中
    • Tensor Parallelism All-Reduce Communication Cost中
  5. 5

    Agent / CUA

    学
    给模型接工具、状态、超时、重试和日志。
    做
    在一个可控网页里跑任务。
    验
    每一步都有记录：它看到什么、做了什么、环境怎么回应。
    练
    • ReAct Agent Loop: Parse Actions, Call Tools, Feed Back Observations中
    • Validate and Execute Model Tool Calls into Chat History中
    • A Stateful Graph Engine for Agent Workflows中
    • Async API Call with Retries, Exponential Backoff and Retry-After中
    • Structured Output: Validate Against a Schema, Retry With the Errors中

    题库里没有网页或 computer-use 的题，可控网页环境要自己搭。

  6. 6

    Evals 与面试

    学
    用独立检查器判定任务是否完成。
    做
    固定模型，对比两版 harness。
    验
    每个失败都归进三类之一：规划、工具执行、评分。
    交
    整理一页项目说明，和之前做 agent 评测的经历接起来。
    练
    • Code Execution Verifier for Programming Benchmarks中
    • Agent Trajectory Metrics: Completion, Tool Precision and Recall, Efficiency中
    • pass^k: Reliability over Repeated Trials versus pass@k中
    • McNemar's Test: Is One Classifier Really Better on the Same Test Set?易
    • Cohen's Kappa and Judge Position Bias易

    把失败归成规划、工具执行、评分三类，没有对应的题，要自己读日志。
